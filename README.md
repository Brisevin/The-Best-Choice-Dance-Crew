# 🕺 The Best Choice Dance Crew

A PHP-based web application for managing dance crew members, schedules, and activities for **The Best Choice Dance Crew**.

## ✨ Features

* **Member Management:** Add, update, and organize dance crew member profiles and roles.
* **Schedule & Rehearsals:** Track practice sessions, dance routines, and training timetables.
* **Events & Performances:** Manage upcoming shows, competitions, and bookings.
* **Media & Showcase:** Highlight crew performances, photos, and announcements.

## 🛠️ Technologies Used

* **Backend:** PHP
* **Database:** MySQL / MariaDB
* **Frontend:** HTML5, CSS3, JavaScript (Bootstrap / Tailwind)
* **Server:** Apache / Nginx (XAMPP, WAMP, or Laragon for local development)
